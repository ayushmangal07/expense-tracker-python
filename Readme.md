# Expense Tracker

A command-line Expense Tracker built using Python, MySQL, and Matplotlib.

## Features

- Add Expense
- View Expenses
- Update Expense
- Delete Expense
- Search by Category
- Search by Date
- Search by Amount Range
- Expense Statistics
- Category-wise Statistics
- Expense Distribution Pie Chart
- Category-wise Bar Chart
- Monthly Expense Analysis

## Technologies Used

- Python
- MySQL
- Matplotlib
